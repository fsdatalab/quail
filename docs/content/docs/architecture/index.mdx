DataFusion parses, plans, and runs SQL. Quail plans and runs each
**model region**: the AI calls and the operators that run with them
on the GPU.

## How Quail executes a query

1. **Build the logical plan.** DataFusion binds the SQL. Quail represents
   each AI call with an `AiNode` in that plan.
2. **Apply optimizer rules.** DataFusion and Quail rewrite the plan.
   Quail then groups AI calls and their required operators into model regions.
3. **Choose a physical plan for each model region.** Quail's planner
   compares operator orders and GPU settings using estimated GPU time.
4. **Run the query.** DataFusion supplies each model region's inputs.
   Quail returns the region's rows to DataFusion for the remaining SQL
   operations.
5. **Read the results.** `query.run()` returns a `QueryResult`.
   `result.collect()` returns its rows as an Arrow table.
