---
title: Reports and plots
description: Where experiment history lives and how to change it.
---

Experiment reports, plot code, figures, and the engine reference are kept
off `main`. Their dedicated branch is `cursor/reports-dev-f955`.

Feature branches that target `main` do not add a shipped-feature report.
Code, tests, and user-facing documentation should explain the current
behavior without requiring readers to search dated experiment notes.

## Work on a report

Start a report change from the report branch:

```bash
git fetch origin cursor/reports-dev-f955
git switch -c cursor/<report-name>-f955 \
  origin/cursor/reports-dev-f955
```

Commit the report, its plot script, and any generated figure to that branch.
Target its pull request back to `cursor/reports-dev-f955`, not `main`.

Experiment data still lives on the `quail-results` Modal volume. Do not
commit result JSON, Parquet answer tables, or Modal logs.

## Link from main-line documentation

When current documentation needs measured evidence, link to the saved Modal
run or to a file on the report branch. Pin a figure link to a commit so it
does not change when the report branch moves.

The detailed QUAIL-B plotting rules and historical engine wiki remain on the
report branch with the files they govern.
