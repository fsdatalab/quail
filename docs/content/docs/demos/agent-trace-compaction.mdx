---
title: Agent trace compaction
---

Use a join to decide which tool calls to keep in OpenHands traces.
The [script][demoscript] adapts [fast Jev compaction][fastjev] and runs
DiffusionGemma 26B-A4B fp8 on H100 GPUs.

## Data preparation

### Sample trajectories

The script samples one trace per issue from
[SWE Zero OpenHands][dataset]. Set `--limit` to the number of issues.
The same `--seed` selects the same sample.

### Build retention questions

For each tool call eligible for removal, the script creates two questions:

- Must the call and its arguments stay in the history?
- Must the full tool output stay in the history?

The `tool_questions` table stores these questions. The `conversations`
table stores a shortened history for each trace. The model reads status
notes in place of the original tool outputs.

## Run the query

The join matches each question to its trace. It returns only the
questions that `AI.IF` answers `TRUE`.

E.g., query the tables prepared by the script:

```sql
SELECT c.id, q.id, q.tool_call_id, q.kind
FROM conversations c
JOIN tool_questions q
  ON c.id = q.conversation_id
 AND AI.IF(PROMPT(
     'Using the compaction state in DOCUMENT {0}, evaluate whether
      the retention statement in DOCUMENT {1} is true.',
     c.state, q.statement
 ))
```

The script also reads the join's answers, including `FALSE`, to rebuild
the traces. It keeps a call when its full output must stay. Otherwise,
it shortens the output if the call must stay, or removes the call.

## Run the example

Run from the repository root after [development setup](/docs/contributing).

### Run locally

E.g., compact 100 traces on one H100:

```bash
uv run python demos/agent_trace_compaction.py \
  --output-dir /tmp/compaction --limit 100 --seed 42
```

Set `--gpus` to 1, 2, 4, or 8. Each GPU holds one model copy.

### Run on Modal

E.g., run the [Modal wrapper][modalscript] on one H100:

```bash
uv run modal setup
uv run modal run --detach demos/agent_trace_compaction_modal.py \
  --limit 100 --seed 42 \
  2>&1 | tee /tmp/quail-agent-compaction.log
```

### Inspect the results

Local runs save files under `<output-dir>/<run-id>/`. Modal runs save
files under `demos/agent-compaction/<run-id>/` on the `quail-results` volume.

| Path | Contents |
| --- | --- |
| `inputs.json` | Sample settings |
| `plan.txt` | Query plan |
| `decisions.parquet` | Boolean answer to each retention question |
| `execution.json` | Query measurements |
| `compacted/` | Compacted OpenHands traces |
| `summary.json` | Character counts and action totals |

This demo measures compaction, not whether an agent completes its task
after compaction.
