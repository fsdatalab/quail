Filter toxic comments from [Civil Comments][dataset] and join them to
classification criteria. The demo samples 10,000 comments by default.

## Query

The query returns a `(comment_id, field)` pair when both AI calls answer
`TRUE`:

- `comments(comment_id, text)` holds the comments.
- `fields(field, statement)` holds 30 criteria for toxicity subtypes and
  identity mentions. Each statement includes positive and negative examples.

E.g., build the query with the demo's prompts:

```python
from demos.civil_comments import FILTER_PROMPT, JOIN_PROMPT

SQL = f"""
SELECT c.comment_id, f.field
FROM comments c
JOIN fields f
  ON AI.IF(PROMPT('{JOIN_PROMPT}', c.text, f.statement))
WHERE AI.IF(PROMPT('{FILTER_PROMPT}', c.text))
"""
```

## Model

The demo uses [DiffusionGemma 26B-A4B fp8][diffusion-gemma] on an H100.

## Execution

The script prints `query.explain()` and saves it as `plan.txt`.
Use it to inspect the filters and join before comparing measurements.

## Results

The script saves matching pairs in `retained.parquet`.
Its `summary.json` contains query time and GPU cost, plus filter and
join F1 scores. The scores compare answers with human ratings at a
threshold of 0.5. Query time and cost exclude model startup.

## Run

Run from the repository root after [development setup](/docs/contributing).
The source is in
[`demos/civil_comments/`](https://github.com/fsdatalab/quail/tree/main/demos/civil_comments).

<Tabs items={['Local H100', 'Modal']}>
<Tab>

E.g., run on one local H100:

```bash
uv run python demos/civil_comments/quail_backend.py \
  --limit 10000 --gpus 1 \
  --output results/civil-comments/quail/local
```

The output directory must not exist before the run.

</Tab>
<Tab>

E.g., run on one Modal H100:

```bash
uv run modal run --detach demos/civil_comments/quail_modal.py \
  --limit 10000 --gpus 1 \
  2>&1 | tee /tmp/civil-comments-quail.log
```

The wrapper prints the Modal function call ID. It saves files under
`demos/civil-comments/quail/<run-id>/` on the `quail-results` volume.

</Tab>
</Tabs>
