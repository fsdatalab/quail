---
title: IMDB review filter
---

Filter the [Stanford IMDB reviews][dataset] for reviews that discuss the
ending and recommend the movie. The [script][demoscript] reads all
100,000 reviews and runs Qwen3 4B fp8.

## The query

E.g., require `TRUE` from both AI calls:

```sql
SELECT r.review_id
FROM reviews AS r
WHERE AI.IF(
    PROMPT('Does this review discuss the ending of the movie?\n\n{0}', r.review),
    {'selectivity': 0.25}
)
AND AI.IF(
    PROMPT('Does the reviewer recommend watching the movie?\n\n{0}', r.review),
    {'selectivity': 0.5}
)
```

The `selectivity` values estimate the fraction of reviews each filter
keeps. They guide planning; they are not answer thresholds.

## Run the example

Run from the repository root after [development setup](/docs/contributing).
E.g., use one H100 SXM:

```bash
uv run python demos/imdb_ending_filter.py
```

Set `--device` to change the GPU type. Set `--gpus` to 1, 2, 4, or 8.
The script prints matching review counts and per-filter selectivity.
It also prints query time and GPU cost. It reports startup separately.
