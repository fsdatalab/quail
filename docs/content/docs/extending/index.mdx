Choose an extension interface for the change you need:

## Extension types

| Task | Guide |
| --- | --- |
| Read tables from another storage system. | [Custom data sources](/docs/extending/table-providers) |
| Add a checkpoint or GPU specification. | [Custom models and GPUs](/docs/extending/models) |
| Add an operator to a physical plan. | [Custom operators](/docs/extending/operators) |
| Change planning decisions. | [Custom Rules](/docs/extending/rules) |
| Add a report from operator measurements. | [Observers](/docs/extending/observers) |
| Use Quail from Rust or an existing DataFusion session. | [Quail from Rust](/docs/extending/datafusion) |

## Registration

`ExtensionRegistry` holds the implementations available to a session.

1. Create a registry with `ExtensionRegistry.with_built_ins()`.
2. Add your implementation with its `register_*` method.
3. Pass the registry to `Session(config=config, registry=registry)`.

Registration does not load model weights. Duplicate registrations raise
`ValueError`. Data sources instead use `session.register(name, provider)`.

## Extension modules

A package can expose `register_quail_extension(registry)` to register
its extensions. Call `registry.load_extension(module_name)` to import
that module and run the function. The module must be importable in that
process. Loading it twice into the same registry raises `ValueError`.
