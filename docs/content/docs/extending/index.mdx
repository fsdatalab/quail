title: Overview
---

Quail's behavior can be extended by registering objects on an
`ExtensionRegistry`. The registry holds models, devices, inference
engines, node types, optimizer rules, and observers. Built-in
components register through the same interface.

## Creating a registry

```python
import quail

registry = quail.ExtensionRegistry.with_built_ins()
```

`with_built_ins()` populates the registry with Quail's included
models, devices, backends, node codecs, and node runtimes. No model
weights are loaded at registration time.

## Registering extensions

Each `register_*` method returns the registry, so calls can be
chained:

```python
registry = (
    quail.ExtensionRegistry.with_built_ins()
    .register_model(MY_MODEL)
    .register_device(MY_DEVICE)
    .register_observer(MyObserver)
)
```

Pass the registry when creating a session:

```python
session = quail.Session(config=config, registry=registry)
```

## What can be registered

| Method | What it registers |
| --- | --- |
| `register_model(spec)` | A [`ModelSpec`](/docs/extending/models). |
| `register_device(spec)` | A [`DeviceSpec`](/docs/extending/models). |
| `register_backend(backend)` | A [custom inference engine](/docs/extending/backends). |
| `register_observer(factory)` | An [execution observer](/docs/extending/observers). |
| `register_logical_rule(rule)` | A [logical rule](/docs/extending/rules). |
| `register_physical_planner(planner)` | A planner that proposes physical plans. |
| `register_physical_rule(rule)` | A [physical rule](/docs/extending/rules). |
| `register_node(node_type, runtime=...)` | A [physical node type](/docs/extending/operators) with its codec and runtime. |

Every name is checked for duplicates. Registering the same name
twice raises `ValueError`.

Table providers are registered on the session with
`session.register(name, provider)`. They do not go through the
extension registry.

## Load an extension module

An extension package can register everything in one function. Write
`register_quail_extension(registry)` in a module:

```python
# my_extension.py
def register_quail_extension(registry):
    registry.register_model(MY_MODEL)
    registry.register_logical_rule(MyRule())
```

Then load the module by name:

```python
registry = quail.ExtensionRegistry.with_built_ins()
registry.load_extension("my_extension")
```

A module loads one time. A second load raises `ValueError`.

## On Modal

Create the registry inside the GPU function. Add extension packages
to the Modal image:

```python
image = image.pip_install("my-extension==1.0.0")
image = image.add_local_python_source("my_package")
```
