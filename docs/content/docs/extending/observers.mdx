---
title: Execution observers
description: Recording per node metrics without changing the plan.
---

An observer sees every physical node once, after it runs, with the
node's outputs and metrics. It cannot change values. Its report is
attached to the query result.

```python
class ExecutionObserver(Protocol):
    name: str
    def after_node(self, node: PhysicalNode, result: NodeResult) -> None: ...
    def report(self) -> Mapping[str, Any]: ...
```

You register a factory, not an instance. The worker creates a fresh
observer per query.

## The example extension: a cost ledger

`quail_ext_examples/cost_ledger.py` charges a query's GPU time and
tokens to the nodes that used them, which is what a chargeback or a
query cost dashboard needs:

```python
H100_USD_PER_HOUR = 3.9492   # https://modal.com/pricing


class CostLedger:
    name = "example.cost_ledger"
    usd_per_gpu_hour = H100_USD_PER_HOUR
    gpus = 1

    def __init__(self):
        self._rows = []

    def after_node(self, node, result) -> None:
        metrics = result.metrics
        usd = metrics.wall_s / 3600 * self.usd_per_gpu_hour * self.gpus
        self._rows.append({
            "node_id": node.node_id,
            "node_type": node.type_name,
            "wall_s": round(metrics.wall_s, 6),
            "evaluated_documents": metrics.evaluated_documents,
            "evaluated_document_pairs": metrics.evaluated_document_pairs,
            "fresh_tokens": metrics.fresh_tokens,
            "cached_tokens": metrics.cached_tokens,
            "usd": round(usd, 8),
        })

    def report(self) -> dict:
        totals = {key: sum(row[key] for row in self._rows)
                  for key in ("wall_s", "fresh_tokens", "usd")}
        return {"nodes": list(self._rows), "totals": totals}


def register_quail_extension(registry) -> None:
    registry.register_observer(CostLedger.name, CostLedger)
```

Load it and the report gains an `observers` key:

```python
registry = quail.ExtensionRegistry.with_built_ins()
registry.load_extension("quail_ext_examples.cost_ledger",
                        local_python_sources=("quail_ext_examples",))
session = quail.Session(registry=registry)
...
result.report["observers"]["example.cost_ledger"]["totals"]
```

The ledger prices every node's wall time on one GPU. Set `gpus` on a
subclass for a node that ran on several.

## What metrics a node reports

`NodeMetrics` has `wall_s`, `input_rows`, `output_rows`,
`evaluated_documents`, `evaluated_document_pairs`, `fresh_tokens`,
`cached_tokens`, `kv_hits`, `kv_misses`, `kv_removals`,
`kv_recomputations`, `regret_tokens`, `peak_gpu_bytes`, and an
`extension` mapping for anything else. Model nodes carry the numbers
the GPU executor measured. `HashJoin`, `Project`, and `Limit` report
row counts.

Observers see model nodes and the Arrow nodes in one pass because the
worker runs the full graph once with the model outputs supplied.
