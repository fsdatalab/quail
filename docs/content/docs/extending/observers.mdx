---
title: Observers
---

An observer runs after each physical node executes. Use observers
for logging, progress reporting, or collecting custom metrics during
query execution.

## Reading metrics without an observer

Every finished query carries per-node metrics on the result:

```python
result = query.run()
result.node_metrics         # node id -> NodeMetrics
print(result.explain())     # prints the plan with measured metrics
```

`NodeMetrics` fields: `wall_s`, `input_rows`, `output_rows`,
`evaluated_documents`, `evaluated_document_pairs`, `fresh_tokens`,
`cached_tokens`, `kv_hits`, `kv_misses`, `kv_removals`,
`kv_recomputations`, `peak_gpu_bytes`, and an `extension` dict.

For most use cases, reading `result.node_metrics` after the query
is sufficient. Observers are for when something needs to happen
during execution.

## The observer protocol

```python
class ExecutionObserver(Protocol):
    name: str
    def after_node(self, node: PhysicalNode, result: NodeResult) -> None: ...
    def report(self) -> Mapping[str, Any]: ...
```

Source:
[quail/runtime/runner.py](https://github.com/fsdatalab/quail/blob/main/quail/runtime/runner.py).

`after_node` is called once per physical node, in execution order,
with the node's outputs and metrics. The observer cannot modify
values. `report()` is called after execution and attached to
`result.report["observers"]`.

## Example: logging progress

```python
import logging


class Progress:
    name = "my.progress"

    def __init__(self):
        self.seen = []

    def after_node(self, node, result):
        self.seen.append(node.node_id)
        logging.info("%s done in %.2fs", node.node_id,
                     result.metrics.wall_s)

    def report(self):
        return {"nodes_executed": list(self.seen)}
```

## Registration

Register the class (the runner creates a fresh instance per query):

```python
registry = (
    quail.ExtensionRegistry.with_built_ins()
    .register_observer(Progress)
)
```

Read the report after execution:

```python
result = query.run()
result.report["observers"]["my.progress"]["nodes_executed"]
```
