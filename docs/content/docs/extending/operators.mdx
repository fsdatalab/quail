---
title: Custom operators
---

Use an `ExtensionNode` to add an operator to a physical plan. Implement
`NodeRuntime.execute()` to run it, then register that implementation.
Registration alone does not add the node to queries.

## Build the node and the NodeRuntime

An `ExtensionNode` declares its ports and stores its settings:

| Field | Purpose |
| --- | --- |
| `type_name` | Selects the registered `NodeRuntime`. It must not use a built-in node's type name. |
| `inputs` | Connects each `InputPort` to another node's `OutputPort` through a `PortRef`. |
| `outputs` | Declares the names, value types, and schemas the operator returns. |
| `location` | Defaults to `COORDINATOR`. Use `GPU_EXECUTOR` to run in the GPU process. |
| Other keyword arguments | Store settings as attributes. Values must be scalar values or containers of scalar values. |

E.g., this node keeps the first ten documents from the `rows:d` port of
an upstream node `input:d`:

```python
from quail.execution.metrics import NodeResult
from quail.physical import (
    ExtensionNode, InputPort, OutputPort, PortRef, ValueType,
)


class FirstDocumentsRuntime:
    def execute(self, node, inputs, context):
        rows = inputs["input:0"]
        kept = rows.take(range(min(len(rows), node.count)))
        return NodeResult({f"rows:{node.alias}": kept})


node = ExtensionNode(
    "example.first_documents", "first:d",
    inputs=(InputPort(
        "input:0", ValueType.ROWS, PortRef("input:d", "rows:d"),
        schema=("d",),
    ),),
    outputs=(OutputPort("rows:d", ValueType.ROWS, schema=("d",)),),
    alias="d", count=10,
)
```

`execute(node, inputs, context)` must return a `NodeResult` with exactly
one value for each declared output port. Connected ports must have
compatible value types and schemas.

## Register the operator

E.g., register the implementation under the node's `type_name`:

```python
from quail import ExtensionRegistry

registry = ExtensionRegistry.with_built_ins()
registry.register_runtime(FirstDocumentsRuntime(), key="example.first_documents")
```

Pass the registry to the session. Register the implementation in each
process that executes the plan.

## Add the operator to a plan

Insert the node through [plan editing](/docs/user-guide/editing-plans),
or write a [physical rule](/docs/extending/rules) that inserts and connects
it. See [ScanRuntime](https://github.com/fsdatalab/quail/blob/main/quail/execution/runtimes/relational.py)
for a built-in `NodeRuntime` implementation.
