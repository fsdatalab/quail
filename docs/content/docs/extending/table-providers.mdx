---
title: Custom data sources
---

Implement `TableProvider` to read a custom source as Arrow record batches.
For supported file formats, use a
[built-in provider](/docs/user-guide/sessions#registering-tables).

## Implement a provider

E.g., this provider reads a fixed snapshot of review dictionaries:

```python
from uuid import uuid4

import pyarrow as pa

from quail.catalog import ScanRequest, TableProvider, TableStatistics


class RowsProvider(TableProvider):
    id_col = "id"

    def __init__(self, rows: list[dict]):
        self._table = pa.Table.from_pylist(rows)
        self._identity = f"rows:{uuid4().hex}"

    @property
    def columns(self):
        return tuple(self._table.column_names)

    def schema(self):
        return self._table.schema

    def content_identity(self):
        return self._identity

    def statistics(self):
        return TableStatistics(
            num_rows=self._table.num_rows,
            num_bytes=self._table.nbytes,
        )

    def scan(self, request: ScanRequest):
        if request.filter is not None:
            raise ValueError("RowsProvider does not support scan filters")
        table = self._table.select(list(request.columns))
        if request.limit is not None:
            table = table.slice(0, request.limit)
        return table.to_reader(max_chunksize=request.batch_rows)
```

## Register the provider

E.g., with an existing local `session`:

```python
session.register("reviews", RowsProvider([
    {"id": "r1", "body": "The acting was excellent."},
    {"id": "r2", "body": "The plot was confusing."},
]))
```

## Requirements

- Change `content_identity()` when values, row order, or schema change.
  Quail uses this identity to reuse tokenized documents. For this example,
  create a new provider when the reviews change.
- Return the requested columns and respect `request.limit`.
- Keep each batch within `request.batch_rows`.
- Apply scan filters before the row limit. Reject filters you cannot apply.
- Read large sources in batches rather than keeping them all in memory.

See the [provider interface](https://github.com/fsdatalab/quail/blob/main/quail/catalog/providers.py)
for types and built-in implementations.
