Quail is a query engine for
[AI-SQL](/docs/user-guide/sql#what-is-ai-sql). You write a SQL query
with AI-powered filters and joins, register your document tables,
and Quail runs the whole query on one or more GPUs.

```sql
SELECT r.id
FROM reviews r
WHERE AI.IF(PROMPT('Does this review discuss the ending?\n\n{0}', r.body))
```

Quail supports two AI-SQL dialects
([Snowflake](https://docs.snowflake.com/en/user-guide/snowflake-cortex/aisql)
and
[BigQuery](https://cloud.google.com/blog/products/data-analytics/sql-reimagined-for-the-ai-era-with-bigquery-ai-functions))
and a [Python builder API](/docs/user-guide/python-api).

## Requirements

- Python 3.12
- Qwen3 4B fp8 or Qwen3 32B fp8
  ([more models coming](/docs/user-guide/models))
- One CUDA GPU per model copy (local, or H100s on
  [Modal](/docs/user-guide/models#no-local-gpu-use-modal))
