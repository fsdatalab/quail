```bash
uv pip install quail-engine
```

The package is `quail-engine`, and you import it as `quail`. With no
local GPU, run Quail on [Modal](/docs/user-guide/models#no-local-gpu-use-modal)
or connect to [Quail Server](/docs/user-guide/server).
