Quail runs SQL with AI functions: SQL functions answered by a language
model on a GPU.

The query below returns the IDs of reviews discussing a movie's ending.
The `reviews` table has an `id` column and review text in `body`:

```sql
SELECT r.id
FROM reviews r
WHERE AI.IF(PROMPT('Does this review discuss the ending? {0}', r.body));
```

`AI.IF` keeps a row when the model answers yes. Other
[AI functions](/docs/user-guide/sql/ai-functions) return scores or labels,
copy answers from documents, or write text.

Quail runs the AI functions on the GPU, and
[Apache DataFusion](https://datafusion.apache.org/) runs the rest of
the SQL.

## Requirements

- Quail needs Python 3.12.
- Quail needs a [supported model and CUDA GPU](/docs/user-guide/models).
  Each GPU holds one complete copy of the model.
- Use [Modal](/docs/user-guide/models#no-local-gpu-use-modal) or connect
  to [Quail Server](/docs/user-guide/server) when you have no local GPU.

## Get started

Install [quail-engine](https://pypi.org/project/quail-engine/):

```bash
uv pip install quail-engine
```
