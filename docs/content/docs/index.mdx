Quail runs SQL with AI functions. DataFusion parses, plans, and runs
SQL around *model regions*: AI calls and the operators Quail runs with
them on the GPU.

E.g., this query returns IDs of reviews that discuss the movie's ending.
The `reviews` table has an `id` column and review text in `body`:

```sql
SELECT r.id
FROM reviews r
WHERE AI.IF(PROMPT('Does this review discuss the ending? {0}', r.body));
```

`AI.IF` keeps rows when the model answers `TRUE`. Other
[AI functions](/docs/user-guide/sql/ai-functions) return scores or labels,
copy answers from documents, or write text.

## Requirements

- Python 3.12.
- A [supported model and CUDA GPU](/docs/user-guide/models).
  Each GPU holds one complete model copy.
- Without a local GPU, use [Modal](/docs/user-guide/models#no-local-gpu-use-modal)
  or connect to [Quail Server](/docs/user-guide/server).

## Get started

Install [quail-engine](https://pypi.org/project/quail-engine/):

```bash
uv pip install quail-engine
```
