Quail (QUery Aware Inference Layer) is an open-source, extensible
query engine for AI functions in SQL. We develop Quail at
[Full Stack Data Lab](https://fsdatalab.github.io/) at CMU.

You can use AI functions to write instructions in natural language
for a language model to evaluate on your data.

For example, imagine a `reviews` table with a movie review ID in `id`
and review text in `body`. The query below returns the IDs of reviews
that discuss the movie's ending:

```sql
SELECT r.id
FROM reviews r
WHERE AI.IF(PROMPT('Does this review discuss the ending?\n\n{0}', r.body));
```

The model answers the question for each review. Quail returns the
review ID when the answer is `TRUE`.

Quail supports AI functions for filtering rows, joining tables,
scoring documents, and assigning classification labels. You can also
use `EXISTS` and `NOT EXISTS` in queries. See the
[SQL reference](/docs/user-guide/sql) for the supported functions.

Quail supports two AI-SQL dialects
([Snowflake](https://docs.snowflake.com/en/user-guide/snowflake-cortex/aisql)
and
[BigQuery](https://cloud.google.com/blog/products/data-analytics/sql-reimagined-for-the-ai-era-with-bigquery-ai-functions))
and a [Python builder API](/docs/user-guide/python-api).

## Requirements

- Python 3.12
- Qwen3 4B fp8, Qwen3 32B fp8, or DiffusionGemma 26B-A4B fp8
  ([all models](/docs/user-guide/models))
- One CUDA GPU per model copy (local, or on
  [Modal](/docs/user-guide/models#no-local-gpu-use-modal))

## Get started

Install [quail-engine from PyPI](https://pypi.org/project/quail-engine/):

```bash
uv pip install quail-engine
```
