A query reads from tables registered on the session. Each table is a
`TableProvider`. `quail.DocumentProvider` has factories for the built
in ones.

```python
import quail

config = quail.EngineConfig(
    gpus=1,
    model="qwen3-4b-fp8",
    backend="quail",
    device="h100-sxm",
)
session = quail.Session(config)
session.register("reviews", quail.DocumentProvider.from_table(
    reviews,          # the IMDB table built in the quickstart
    id_col="id",
))
```

Every provider needs an `id_col`. It is the column that identifies a
document. Result rows are built from document positions, and the id
column is what you normally select.

## Built in providers

| Factory | Source |
| --- | --- |
| `from_table(table, id_col, identity="memory")` | An in memory Arrow table |
| `from_parquet(path_or_paths, id_col)` | Parquet file, directory, or list |
| `from_ipc(path, id_col)` | Arrow IPC file |
| `from_dataset(dataset, id_col)` | Any `pyarrow.dataset.Dataset` |
| `from_hf(dataset, id_col, split="train", config="")` | A Hugging Face dataset |

All providers read data in the session's process. Quail reads bounded
batches of the id, document, and projected columns. It tokenizes documents
into temporary memory mapped Arrow files.

On Modal, create and register providers inside the GPU function. For
remote Parquet, pass the path to that function. For data available only
on your machine, pass an Arrow table and register it with `from_table`.
Modal transfers function arguments; Quail does not transfer data automatically.

If a source needs credentials, make them available in the query process.
On Modal, attach a secret to the function with
`secrets=(modal.Secret.from_name("quail-s3"),)`. See
[Running on Modal](/docs/user-guide/compute).

## The identity of a table

The session tokenizes each document column once per session and keys
the token store by the provider's `content_identity()`. The Parquet
and dataset providers derive it from the file list. The memory
provider uses the `identity` argument, so pass a distinct identity when
two in memory tables differ but share a name.

## The TableProvider interface

You can register any object that implements this protocol. It does not
need a registry entry.

```python
class TableProvider(Protocol):
    id_col: str

    @property
    def columns(self) -> tuple[str, ...]: ...
    def schema(self) -> pa.Schema: ...
    def content_identity(self) -> str: ...
    def statistics(self) -> TableStatistics: ...
    def scan(self, request: ScanRequest) -> pa.RecordBatchReader: ...
```

- `scan` returns bounded record batches for the columns in
  `ScanRequest.columns`.
