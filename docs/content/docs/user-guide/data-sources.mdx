---
title: Data sources
description: Registering tables from Arrow, Parquet, Hugging Face, or your own provider.
---

A query reads from tables registered on the session. Each table is a
`TableProvider`. `quail.DocumentProvider` has factories for the built
in ones.

```python
import quail

session = quail.Session()
session.register("reviews", quail.DocumentProvider.from_table(
    reviews,          # the IMDB table built in the quickstart
    id_col="id",
))
```

Every provider needs an `id_col`. It is the column that identifies a
document. Result rows are built from document positions, and the id
column is what you normally select.

## Built in providers

| Factory | Source | Read where |
| --- | --- | --- |
| `from_table(table, id_col, identity="memory")` | An in memory Arrow table | Client sends the needed columns to the worker |
| `from_parquet(path_or_paths, id_col)` | Parquet file, directory, or list | Worker opens it when the path is remote, otherwise client sends columns |
| `from_ipc(path, id_col)` | Arrow IPC file | Client sends columns |
| `from_dataset(dataset, id_col)` | Any `pyarrow.dataset.Dataset` | Worker opens it when the dataset is remote |
| `from_hf(dataset, id_col, split="train", config="")` | A Hugging Face dataset | Worker opens it |

"Remote" means a path such as `s3://` or `gs://` that the Modal worker
can open itself. For those, the client reads only the schema and file
list so it can check column names. It never reads document rows. The
worker reads bounded batches, tokenizes them, and writes the tokens to
a temporary memory mapped Arrow file.

For a client-only source, the client reads just the columns the query
uses (the id column, the document column, and the projected columns)
and sends them as raw Arrow. The worker tokenizes them.

If the worker needs credentials to open a remote source, give the
compute provider a Modal secret:

```python
import modal

compute = quail.ModalComputeProvider(secrets=(
    modal.Secret.from_name("quail-s3"),
))
session = quail.Session(compute_provider=compute)
session.register("documents", quail.DocumentProvider.from_parquet(
    "s3://my-bucket/documents.parquet", id_col="document_id",
))
```

## The identity of a table

The session tokenizes each document column once per session and keys
the token store by the provider's `content_identity()`. The Parquet
and dataset providers derive it from the file list. The memory
provider uses the `identity` argument, so pass a distinct identity when
two in memory tables differ but share a name.

## The TableProvider interface

You can register any object that implements this protocol. It does not
need a registry entry.

```python
class TableProvider(Protocol):
    id_col: str

    @property
    def columns(self) -> tuple[str, ...]: ...
    def schema(self) -> pa.Schema: ...
    def content_identity(self) -> str: ...
    def statistics(self) -> TableStatistics: ...
    def scan(self, request: ScanRequest) -> pa.RecordBatchReader: ...
    def remote_source(self) -> Mapping[str, Any] | None: ...
```

- `scan` returns bounded record batches for the columns in
  `ScanRequest.columns`.
- `remote_source` returns a small mapping the worker can open on its
  own, or `None` for a client-only source. The mapping's `type` key
  selects a registered source reader on the worker. See
  [Table providers](/docs/extending/table-providers) for a full
  example.
