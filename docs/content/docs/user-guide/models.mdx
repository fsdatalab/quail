Choose a model for the AI functions in your query, then choose a GPU able to
run the model. Start with Qwen3 4B on an H100 unless your query needs a
specialized model.

import quail

config = quail.EngineConfig(

    device="h100-sxm",

## General-purpose models

Every model in the table supports `AI.IF`, `AI.SCORE`, `AI.CLASSIFY`,
`AI.EXTRACT`, `AI.EXTRACT_SPAN`, and `AI.MAP`.

| Model | `model` value | Precision |
| --- | --- | --- |
| Qwen3 4B | `qwen3-4b-fp8` | FP8 |
| Qwen3 32B | `qwen3-32b-fp8` | FP8 |
| Qwen3.5 4B | `qwen3.5-4b-bf16` | BF16 |
| Qwen3.5 4B | `qwen3.5-4b-fp8` | FP8 and BF16 |
| Qwen3.5 27B | `qwen3.5-27b-fp8` | FP8 |
| Qwen3.6 35B-A3B | `qwen3.6-35b-a3b-fp8` | FP8 |
| Qwen3.8 27B | `qwen3.8-27b-fp8` | FP8 |
| LFM2 2.6B | `lfm2-2.6b-bf16` | BF16 |

FP8 stores each model weight as an 8-bit floating-point number. BF16 stores
each model weight as a 16-bit floating-point number.

## Models with limited functions

| Model | `model` value | Supported AI functions |
| --- | --- | --- |
| DiffusionGemma 26B-A4B | `diffusion-gemma-26b-a4b-fp8` | `AI.IF`, `AI.SCORE`, `AI.CLASSIFY` |
| Decision 2.0 Kai 0.6B | `decision-2.0-kai-0.6b-bf16` | `AI.IF`, `AI.SCORE`, `AI.CLASSIFY` |
| Qwen3 Reranker 0.6B | `qwen3-reranker-0.6b-bf16` | `AI.SCORE` |
| Qwen3 Reranker 4B | `qwen3-reranker-4b-bf16` | `AI.SCORE` |
| d1-2B | `d1-2b-bf16` | `AI.IF`, `AI.SCORE`, `AI.CLASSIFY`, `AI.EXTRACT`, `AI.EXTRACT_SPAN` |
| d1-2B | `d1-2b-fp8` | `AI.IF`, `AI.SCORE`, `AI.CLASSIFY`, `AI.EXTRACT`, `AI.EXTRACT_SPAN` |
| Qwen3.5 2B Base with Qwen-Scope SAE | `qwen3.5-2b-sae-bf16` | `AI.SAE_FEATURES` |

The d1-2B models run `AI.SCORE` over one table only. The FP8 d1-2B model
converts the published BF16 weights to FP8 while loading them.

DiffusionGemma needs a Hugging Face token with access to the
[`RedHatAI/diffusiongemma-26B-A4B-it-FP8-dynamic`](https://huggingface.co/RedHatAI/diffusiongemma-26B-A4B-it-FP8-dynamic)
weights. Set the token in `HF_TOKEN` before Quail loads the model.

Decision 2.0 Kai and the Qwen3 rerankers score supplied answers instead of
writing text. Check their scores against labeled examples before choosing a
threshold.

## GPUs

Set `device` to the value for your GPU:

| GPU | `device` value | Model support |
| --- | --- | --- |
| NVIDIA H100 SXM | `h100-sxm` | All supported models |
| NVIDIA B200 | `b200` | All supported models |
| NVIDIA RTX PRO 6000 Blackwell Server Edition | `rtx-pro-6000-blackwell-server` | All supported models |
| NVIDIA L40S | `l40s` | Qwen3, Qwen3 rerankers, Decision 2.0 Kai, LFM2, and d1-2B |

The L40S cannot run DiffusionGemma or the Qwen3.5, Qwen3.6, and Qwen3.8
models because their attention kernel does not support the L40S. Quail also
checks whether the selected model fits in GPU memory when it plans a query.

## Use more than one GPU

Set `gpus` to `1`, `2`, `4`, or `8`. Each GPU holds one complete model copy,
and each copy runs part of the input rows. Quail does not split one model copy
across several GPUs.

```python
config = quail.EngineConfig(
    model="qwen3-4b-fp8",
    device="h100-sxm",
    gpus=4,
)
```

## Use a remote GPU

Run [Quail Server](/docs/user-guide/server) on a machine with a supported GPU
when your local machine has no supported GPU. Your local client can submit a
query and reconnect while the server continues the run.
