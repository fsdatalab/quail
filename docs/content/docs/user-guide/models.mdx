Set `model` to the model you want to run and `device` to your GPU type.

## Models

| Model | `model` value | Weight precision | AI functions |
| --- | --- | --- | --- |
| Qwen3 4B | `"qwen3-4b-fp8"` | FP8 | `AI.IF`, `AI.SCORE`, `AI.CLASSIFY` |
| Qwen3 32B | `"qwen3-32b-fp8"` | FP8 | `AI.IF`, `AI.SCORE`, `AI.CLASSIFY` |
| DiffusionGemma 26B-A4B | `"diffusion-gemma-26b-a4b-fp8"` | FP8 | `AI.IF`, `AI.SCORE`, `AI.CLASSIFY` |
| Qwen3 Reranker 0.6B | `"qwen3-reranker-0.6b-bf16"` | BF16 | `AI.SCORE` |
| Qwen3 Reranker 4B | `"qwen3-reranker-4b-bf16"` | BF16 | `AI.SCORE` |
| Decision 2.0 Kai 0.6B | `"decision-2.0-kai-0.6b-bf16"` | BF16 | `AI.IF`, `AI.SCORE` |

*FP8* is an 8 bit floating point format. *BF16* is a 16 bit floating point
format. All listed models store KV in BF16.

`AI.IF` supports filters and joins. `AI.SCORE` returns a score, and
`AI.CLASSIFY` assigns a label. See the
[SQL reference](/docs/user-guide/sql#ai-operators) for examples.

## GPUs

| GPU | `device` value |
| --- | --- |
| NVIDIA H100 SXM | `"h100-sxm"` |

## Configure a session

For example, to run Qwen3 4B on one H100 SXM:

```python
import quail

config = quail.EngineConfig(model="qwen3-4b-fp8", device="h100-sxm")
```

Pass `config` to `quail.Session`. Quail downloads the model weights
when they are not already available.

### Use multiple GPUs

Set `gpus` to 1, 2, 4, or 8 GPUs on one machine. The default is one.
Each GPU holds a complete model copy and processes part of the input.
Quail does not split a model's weights across GPUs.

```python
config = quail.EngineConfig(
    model="qwen3-4b-fp8",
    device="h100-sxm",
    gpus=4,
)
```

## DiffusionGemma

DiffusionGemma uses the
`RedHatAI/diffusiongemma-26B-A4B-it-FP8-dynamic` checkpoint.
Set `HF_TOKEN` before running it because access to the weights is gated.

For `AI.CLASSIFY` and `AI.SCORE`, `canvas_draws` limits the number of
attempts per document. The default is four. Quail can make additional
attempts when the first answer's probabilities are spread across labels.
It averages the probabilities from those attempts.

Set `canvas_draws=1` to use one attempt per document:

```python
config = quail.EngineConfig(
    model="diffusion-gemma-26b-a4b-fp8",
    device="h100-sxm",
    canvas_draws=1,
)
```

Classification of joined rows always uses one attempt.
The setting does not change `AI.IF` execution.

## Decision 2.0 Kai 0.6B

[Decision-2.0-Kai-0.6B](https://huggingface.co/vllm-sr/Decision-2.0-Kai-0.6B)
is a decision model from vLLM Semantic Router: a Qwen3-0.6B network
with a separate classifier head. It answers `AI.IF` filters and joins
and `AI.SCORE`, where the score is the head's probability of `Yes` over
`No`. It does not run `AI.CLASSIFY`, and the stock vLLM and SGLang
backends do not run it.

Quail writes each prompt in the model's yes/no question format: the
document after `Context:`, the question, a `No` option block, a `Yes`
option block, and a closing line. In a join the question follows the
anchor document, so it is computed once per anchor; the option blocks
follow the partner document. Quail reads the last token of each option
block and the last token of the prompt, and the head scores both
options in FP32.

On first use Quail converts the checkpoint once to a BF16 Qwen3 folder
under `$HF_HOME/quail-checkpoints/`. The model's own code keeps FP32
weights under BF16 autocast, and Quail tokenizes each document
separately from the fixed prompt text, so answers near a tie can
differ from the model's own code.

```python
config = quail.EngineConfig(
    model="decision-2.0-kai-0.6b-bf16",
    device="h100-sxm",
)
```

## No local GPU? Use Modal

You can run Quail in a [Modal](https://modal.com) GPU function.
Install Modal and authenticate on the machine that submits the function:

```bash
uv pip install modal==1.5.4
modal setup
```

For example, the program below selects movie reviews that praise the
acting. Save it as `run_quail.py`. It runs on one H100 and saves model
weights and compiled kernels on Modal volumes for later runs.

```python
import modal

app = modal.App("quail-engine")
weights = modal.Volume.from_name("quail-hf-cache", create_if_missing=True)
kernels = modal.Volume.from_name("quail-kernel-cache", create_if_missing=True)
image = (
    modal.Image.from_registry(
        "nvidia/cuda:13.0.1-devel-ubuntu24.04", add_python="3.12")
    .entrypoint([])
    .uv_pip_install("quail-engine==0.1.0")
    .env({
        "HF_HOME": "/model-cache",
        "QUAIL_CACHE_DIR": "/kernel-cache/quail",
    })
)

@app.function(
    image=image,
    gpu="H100!",
    memory=98304,
    timeout=1200,
    volumes={"/model-cache": weights, "/kernel-cache": kernels},
)
def run_query():
    import pyarrow as pa
    import quail

    reviews = pa.table({
        "id": ["r1", "r2"],
        "body": ["The acting was excellent.", "The plot was confusing."],
    })
    config = quail.EngineConfig(model="qwen3-4b-fp8", device="h100-sxm")
    with quail.Session(config=config) as session:
        session.register("reviews", quail.DocumentProvider.from_table(
            reviews, id_col="id"))
        result = session.sql("""
            SELECT r.id
            FROM reviews r
            WHERE AI.IF(
                PROMPT('Does this review praise the acting? {0}', r.body))
        """, dialect="bq").run()
        return result.collect(), result.report

@app.local_entrypoint()
def main():
    call = run_query.spawn()
    print(f"function call id: {call.object_id}", flush=True)
    rows, report = call.get()
    print(rows.to_pylist())
    print(report)
```

The example installs Quail 0.1.0 in the GPU image.
Collect the rows inside the session before returning from the function.

### Run and retrieve the result

```bash
modal run --detach run_quail.py 2>&1 | tee run_quail.log
```

Keep the function call ID printed in the log. If you disconnect, retrieve
the result with that ID:

```python
rows, report = modal.FunctionCall.from_id("fc-...").get()
```

The example returns rows and a report. To save them on a Modal volume,
write them to its mounted path and call `volume.commit()` in the function.
