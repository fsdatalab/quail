---
title: Querying PDFs
---

Quail answers questions about a PDF from images of its pages.
`AI.PDF_PAGES` renders the pages, and a model with a vision tower reads
the images. The vision models are `qwen3.5-4b-bf16`, `qwen3.5-4b-fp8`,
`qwen3.5-27b-fp8`, `qwen3.8-27b-fp8`, and `qwen3.6-35b-a3b-fp8`.

## Ask about each page

Put each PDF's bytes in a `BINARY` column, and render the pages in the
query:

```python
from pathlib import Path

import pyarrow as pa
import quail

paths = sorted(Path("contracts").glob("*.pdf"))
files = pa.table({
    "path": [path.name for path in paths],
    "pdf": pa.array([path.read_bytes() for path in paths], pa.binary()),
})
config = quail.EngineConfig(model="qwen3.5-4b-bf16", device="h100-sxm")
with quail.Session(config=config) as session:
    session.register("files", quail.DocumentProvider.from_table(files, id_col="path"))
    print(session.sql("""
        SELECT p.path, p.u['page'] AS page
        FROM (SELECT f.path, UNNEST(AI.PDF_PAGES(f.pdf, 1024)) AS u FROM files f) p
        WHERE AI.IF(PROMPT('Does this page cap either party''s liability? {0}',
                           p.u['image']))
    """).run().collect())
```

The query returns each page that caps liability. `UNNEST` turns each
PDF's list of pages into one row per page.

## Ask about a whole PDF

Pass the pages without `UNNEST` to ask one question of the whole PDF.
The third and fourth arguments of `AI.PDF_PAGES` limit the pages, so a
long PDF costs only the pages you read:

```sql
SELECT f.path,
       AI.CLASSIFY(AI.PDF_PAGES(f.pdf, 1024, 1, 3),
                   ['lease', 'invoice', 'annual report', 'other']) AS kind
FROM files f;
```

## Set the image size

The second argument of `AI.PDF_PAGES` sets the longer side of each
image, in pixels. The model reads one token per 32 by 32 pixels, so a
US Letter page at 1,024 pixels is 800 tokens. Use a larger size for small
print; the default is 1,536.

## Read the text a PDF stores

Quail has no OCR. `AI.PARSE_DOCUMENT` returns the text a PDF stores, and
a scanned page stores none. `AI.EXTRACT` needs text, so read the stored
text to extract from a PDF:

```sql
SELECT f.path,
       AI.EXTRACT(AI.PARSE_DOCUMENT(f.pdf),
                  {'effective_date': 'What is the effective date?'}) AS answers
FROM files f;
```

[AI functions](/docs/user-guide/sql/ai-functions#aipdf_pagespdf-longest_edge-first-last)
lists every argument of both functions.
