---
title: Querying PDFs
---

You can query a dataset of PDFs with SQL, and ask a model about each
page or each PDF. You render the pages with `AI.PDF_PAGES`, and a vision
model reads the page images, so you do not convert the PDFs to text
first. You need a model with a vision tower: `qwen3.5-4b-bf16`,
`qwen3.5-4b-fp8`, `qwen3.5-27b-fp8`, `qwen3.8-27b-fp8`, or
`qwen3.6-35b-a3b-fp8`.

## Find the pages that answer a question

You load each PDF's bytes into a `BINARY` column, then ask the question
of every page. The program below returns each contract page that caps
liability:

```python
from pathlib import Path

import pyarrow as pa
import quail

paths = sorted(Path("contracts").glob("*.pdf"))
files = pa.table({
    "path": [path.name for path in paths],
    "pdf": pa.array([path.read_bytes() for path in paths], pa.binary()),
})
config = quail.EngineConfig(model="qwen3.5-4b-bf16", device="h100-sxm")
with quail.Session(config=config) as session:
    session.register("files", quail.DocumentProvider.from_table(files, id_col="path"))
    print(session.sql("""
        SELECT p.path, p.u['page'] AS page
        FROM (SELECT f.path, UNNEST(AI.PDF_PAGES(f.pdf, 1024)) AS u FROM files f) p
        WHERE AI.IF(PROMPT('Does this page cap either party''s liability? {0}',
                           p.u['image']))
    """).run().collect())
```

`UNNEST` turns each PDF's list of pages into one row per page, so you
get one answer per page.

## Label each PDF

You leave out `UNNEST` to ask one question of a whole PDF. You can also
pass a page range, so a long PDF costs only the pages the model reads.
The query below labels each PDF from its first three pages:

```sql
SELECT f.path,
       AI.CLASSIFY(AI.PDF_PAGES(f.pdf, 1024, 1, 3),
                   ['lease', 'invoice', 'annual report', 'other']) AS kind
FROM files f;
```

## Choose the image size

You set the longer side of each page image, in pixels, with the second
argument of `AI.PDF_PAGES`. The model reads one token per 32 by 32
pixels, so a US Letter page at 1,024 pixels costs 800 tokens. You can
raise the size for small print; the default is 1,536.

## Extract fields from a PDF's text

You need text, not images, to use `AI.EXTRACT`, because it copies each
answer from the document. `AI.PARSE_DOCUMENT` returns the text a PDF
stores. Quail has no OCR, so a scanned page gives you no text:

```sql
SELECT f.path,
       AI.EXTRACT(AI.PARSE_DOCUMENT(f.pdf),
                  {'effective_date': 'What is the effective date?'}) AS answers
FROM files f;
```

[AI functions](/docs/user-guide/sql/ai-functions#aipdf_pagespdf-longest_edge-first-last)
lists every argument of `AI.PDF_PAGES` and `AI.PARSE_DOCUMENT`.
