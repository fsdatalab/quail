---
title: Querying PDFs
---

If you have a dataset of PDFs and want to run analytics on it, use
`AI.PDF_PAGES` to get to pixels. Then ask questions about the pixels.
You do not need to go through a parser to get to text.

## Load PDFs

Store each PDF's bytes in a `BINARY` column:

```python
from pathlib import Path

import pyarrow as pa
import quail

paths = sorted(Path("contracts").glob("*.pdf"))
files = pa.table({
    "path": [path.name for path in paths],
    "pdf": pa.array([path.read_bytes() for path in paths], pa.binary()),
})
config = quail.EngineConfig(model="qwen3.5-4b-bf16", device="h100-sxm")
session = quail.Session(config=config)
session.register("files", quail.DocumentProvider.from_table(files, id_col="path"))
```

## Ask questions about pages

`AI.PDF_PAGES` returns a list of a PDF's pages, each a PNG image. The
`UNNEST` function turns the list into one row per page. The query below
returns each page that caps liability:

```sql
SELECT p.path, p.u['page'] AS page
FROM (SELECT f.path, UNNEST(AI.PDF_PAGES(f.pdf, 1024)) AS u FROM files f) p
WHERE AI.IF(PROMPT('Does this page cap either party''s liability? {0}',
                   p.u['image']));
```

## Ask questions about a whole PDF

An AI function reads the list from `AI.PDF_PAGES` as one document. The
third and fourth arguments of `AI.PDF_PAGES` set the first and last
pages. The query below classifies each PDF from its first three pages:

```sql
SELECT f.path,
       AI.CLASSIFY(AI.PDF_PAGES(f.pdf, 1024, 1, 3),
                   ['lease', 'invoice', 'annual report', 'other']) AS kind
FROM files f;
```

## Choose a model

A model needs a vision tower to read pixels. The models with a vision
tower are `qwen3.5-4b-bf16`, `qwen3.5-4b-fp8`, `qwen3.5-27b-fp8`,
`qwen3.8-27b-fp8`, and `qwen3.6-35b-a3b-fp8`.

## Choose an image size

The second argument of `AI.PDF_PAGES` sets the longest side of each
image, in pixels. The default is 1,536. A model reads one token per 32
by 32 pixels. A US Letter page at 1,024 pixels is 800 tokens.

## Parse to text

Quail does not support a text parser yet. If you absolutely must parse,
`AI.PARSE_DOCUMENT` returns the text a PDF stores. A scanned page stores
no text. `AI.EXTRACT` needs text:

```sql
SELECT f.path,
       AI.EXTRACT(AI.PARSE_DOCUMENT(f.pdf),
                  {'effective_date': 'What is the effective date?'}) AS answers
FROM files f;
```

[AI functions](/docs/user-guide/sql/ai-functions#aipdf_pagespdf-longest_edge-first-last)
lists every argument of `AI.PDF_PAGES` and `AI.PARSE_DOCUMENT`.
