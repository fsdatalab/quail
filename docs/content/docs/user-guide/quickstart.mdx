## Install

```bash
pip install quail-engine
```

Quail requires Python 3.12 and a CUDA GPU (local or on
[Modal](/docs/user-guide/models#no-local-gpu-use-modal)).

## Run a filter query with SQL

This example filters the 100,000 movie reviews in the
[Stanford IMDB dataset](https://huggingface.co/datasets/stanfordnlp/imdb)
on an H100 SXM, keeping reviews that mention a positive aspect of the
movie.

```python
import pyarrow as pa, pyarrow.dataset as ds
import quail
from datasets import concatenate_datasets, load_dataset

imdb = load_dataset("stanfordnlp/imdb")
all_reviews = concatenate_datasets([imdb["train"], imdb["test"], imdb["unsupervised"]])
reviews = ds.dataset(pa.table({
    "id": pa.array(f"review-{i}" for i in range(len(all_reviews))),
    "body": all_reviews.data.table.column("text"),
}))

config = quail.EngineConfig(model="qwen3-4b-fp8", device="h100-sxm")
with quail.Session(config=config) as session:
    session.register("reviews", quail.DocumentProvider.from_dataset(reviews, id_col="id"))
    result = session.sql("""
        SELECT r.id
        FROM reviews r
        WHERE AI_FILTER(PROMPT(
            'Does this review mention a positive aspect of the movie?\n\n{0}',
            r.body))
    """, dialect="snowflake").collect()
    print(result)
```

`session.register()` makes the dataset available under a SQL name.
`AI_FILTER` evaluates the prompt on each review. The model returns
TRUE or FALSE, and Quail returns the rows where the answer is TRUE.

## Python builder API

If you prefer building queries in Python instead of writing SQL, you
can use the builder API:

```python
from quail import col, prompt

config = quail.EngineConfig(model="qwen3-4b-fp8", device="h100-sxm")

with quail.Session(config=config) as session:
    session.register("reviews", quail.DocumentProvider.from_dataset(
        reviews, id_col="id",
    ))
    result = (session.docs("reviews").alias("r")
              .ai_filter(prompt(
                  'Does this review mention a positive aspect of the movie?\n\n{0}',
                  col("r.body")))
              .select("r.id")
              .collect())
```

See the [Python API](/docs/user-guide/python-api) page for the full
reference.
