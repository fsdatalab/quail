## Install

Quail requires Python 3.12 and a
[supported CUDA GPU](/docs/user-guide/models).
Install `quail-engine`; import it as `quail`:

```bash
uv pip install quail-engine
```

## Run an AI filter

E.g., filter the 100,000 reviews in the
[Stanford IMDB dataset](https://huggingface.co/datasets/stanfordnlp/imdb)
on an H100 SXM. Keep reviews that mention a positive aspect of the movie:

```python
import pyarrow as pa
import quail
from datasets import concatenate_datasets, load_dataset

imdb = load_dataset("stanfordnlp/imdb")
all_reviews = concatenate_datasets([imdb["train"], imdb["test"], imdb["unsupervised"]])
reviews = pa.table({
    "id": [f"review-{i}" for i in range(len(all_reviews))],
    "body": all_reviews.data.table.column("text"),
})

config = quail.EngineConfig(model="qwen3-4b-fp8", device="h100-sxm")
with quail.Session(config=config) as session:
    session.register("reviews", quail.DocumentProvider.from_table(reviews, id_col="id"))
    query = session.sql("""
        SELECT r.id
        FROM reviews r
        WHERE AI.IF(PROMPT(
            'Does this review mention a positive aspect of the movie? {0}',
            r.body))
    """, dialect="bq")
    result = query.run()
    print(result.collect())
    print(result.explain())
```

`register()` makes the table available in SQL. `AI.IF` keeps rows when
the model answers `TRUE`. `collect()` returns their IDs in a `pyarrow.Table`.

## See the plan and measured cost

The example prints the measured plan with `result.explain()`.
Use `query.explain()` before `run()` to inspect estimates without
running the model. `query.explain(analyze=True)` runs the query again.

Read query time and token counts from `result.report`.
See [Metrics](/docs/user-guide/metrics) to calculate GPU cost.
