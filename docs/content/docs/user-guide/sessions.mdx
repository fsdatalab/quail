---
title: Running queries
---

A session holds your model configuration and your registered tables.
Reuse one session for every query over the same tables.

## Create a session

Set `model` and `device` in `EngineConfig`; neither has a default.
`gpus` defaults to 1. [Models and GPUs](/docs/user-guide/models) lists
the supported values.

## Register tables

`session.register(name, provider)` makes a table available in SQL under
`name`. Each provider needs an `id_col`, the column identifying a row.

| Factory | Source |
| --- | --- |
| `DocumentProvider.from_table(table, id_col)` | In-memory Arrow table |
| `DocumentProvider.from_parquet(path, id_col)` | Parquet file or directory |
| `DocumentProvider.from_ipc(path, id_col)` | Arrow IPC file |
| `DocumentProvider.from_dataset(dataset, id_col)` | `pyarrow.dataset.Dataset` |
| `DocumentProvider.from_hf(dataset, id_col)` | Hugging Face repository name; optional `split`, `config`, and `revision` |

## Run a query

The program below registers two reviews and filters them:

```python
import pyarrow as pa
import quail

reviews = pa.table({
    "id": ["r1", "r2"],
    "body": ["The acting was excellent.", "The plot was confusing."],
})
config = quail.EngineConfig(model="qwen3-4b-fp8", device="h100-sxm")
with quail.Session(config=config) as session:
    session.register("reviews", quail.DocumentProvider.from_table(reviews, id_col="id"))
    rows = session.sql("""
        SELECT r.id FROM reviews r
        WHERE AI.IF(PROMPT('Is this review positive? {0}', r.body))
    """, dialect="bq").collect()
    print(rows)
```

`sql()` returns a [`Query`](/docs/user-guide/results#read-the-results).
`collect()` runs the query and returns an Arrow table. Use `run()` when
you also need the plan and metrics.

## Run on Quail Server

Pass `endpoint` to submit queries to
[Quail Server](/docs/user-guide/server). Replace the session line in the
program with
`with quail.Session(config=config, endpoint="grpc://127.0.0.1:50051") as session:`.

`sql()` then returns a
[`RemoteQuery`](/docs/user-guide/server#submit-a-query). The server keeps
running an accepted query after the client exits. Save the query ID from
`submit()` to read the query from another client.

## Use several GPUs

Set `gpus` in `EngineConfig`. Each GPU holds one complete copy of the
model. Replace the configuration in the program with
`quail.EngineConfig(model="qwen3-4b-fp8", device="h100-sxm", gpus=4)`
to use four GPUs.
