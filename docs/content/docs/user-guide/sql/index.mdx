Quail accepts SQL with AI functions.
[Apache DataFusion](https://datafusion.apache.org/) parses the SQL and
runs every operator except the AI functions, which Quail runs on the
GPU.

## Write a query

Register a `reviews` table with IDs in `id` and text in `body`. The
query below returns the IDs of reviews discussing the ending:

```sql
SELECT r.id
FROM reviews r
WHERE AI.IF(PROMPT('Does this review discuss the ending? {0}', r.body));
```

Pass the SQL text to `session.sql(text)`. `sql()` reads Snowflake
syntax by default; pass `dialect="bq"` for BigQuery syntax.
`AI_FILTER` is the Snowflake spelling of `AI.IF`.

## SQL around the model's work

Quail groups AI calls reading the same rows into a *model region* and
runs each model region on the GPU. DataFusion runs every other
operator: plain filters, joins, grouping, sorting, and limits.

The query below classifies reviews with more than three stars and
counts each label:

```sql
SELECT AI.CLASSIFY(PROMPT('Tone? {0}', r.body), ['good', 'bad']) AS tone,
       COUNT(*) AS reviews
FROM reviews r
WHERE r.stars > 3
GROUP BY tone
ORDER BY reviews DESC;
```

The model reads only the reviews passing `r.stars > 3`. DataFusion
groups and sorts the labels the model region returns.

`query.explain()` shows the plans. `query.plan()` returns one physical
plan per model region, as a tuple when the query has several model
regions.

Use a [CTE](/docs/user-guide/sql/sql-functions#with) or a `FROM` subquery
when an AI call needs to read an aggregate or window value. DataFusion
computes the value before the next model region reads it.
