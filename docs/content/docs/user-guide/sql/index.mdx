in model regions. Queries without AI calls run in DataFusion.

## Write a query

E.g., register a `reviews` table with IDs in `id` and text in `body`.
This query returns IDs of reviews that discuss the ending:

```sql
SELECT r.id
FROM reviews r
WHERE AI.IF(PROMPT('Does this review discuss the ending? {0}', r.body));
```

Pass SQL text to `session.sql(text, dialect="bq")` for BigQuery syntax.
Use `dialect="snowflake"` for Snowflake syntax, the default.
`AI_FILTER` is the Snowflake spelling of `AI.IF`.

## SQL around the model's work

A *model region* contains AI calls and the operators Quail runs with
them. DataFusion runs the rest of the query.

E.g., classify reviews with more than three stars and count each label:

```sql
SELECT AI.CLASSIFY(PROMPT('Tone? {0}', r.body), ['good', 'bad']) AS tone,
       COUNT(*) AS reviews
FROM reviews r
WHERE r.stars > 3
GROUP BY tone
ORDER BY reviews DESC;
```

The model reads only reviews that pass `r.stars > 3`.
DataFusion groups and sorts the labels that the model region returns.

`query.explain()` shows the plans.
`query.plan()` returns one physical plan per model region.
For a query with several model regions, it returns a tuple of plans.

Use a [CTE](/docs/user-guide/sql/sql-functions#with) or a `FROM` subquery
when an AI call needs to read an aggregate or window value.
DataFusion computes those values before the next model region reads them.
