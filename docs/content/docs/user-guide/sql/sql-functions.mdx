---
title: SQL with AI functions
---

DataFusion defines Quail's SQL grammar and runs every relational operator.
Quail adds the AI functions and plans the model work around the DataFusion
operators.

[DataFusion's SQL reference](https://datafusion.apache.org/user-guide/sql/index.html)
documents SQL clauses, expressions, aggregate functions, and window
functions. The Quail reference documents the behavior added by AI functions.

## Place an AI function

Use an AI function wherever DataFusion accepts its return type:

| SQL location | Use |
| --- | --- |
| `SELECT` | Return an AI answer as a column. |
| `WHERE` | Keep rows based on an AI answer. |
| `JOIN ... ON` | Keep pairs based on an AI answer. |
| `GROUP BY` | Group rows by an AI answer. |
| `HAVING` | Keep groups based on an AI answer. |
| `ORDER BY` | Sort rows by an AI answer. |

[AI functions](/docs/user-guide/sql/ai-functions) lists the return type and
supported locations for each function.

## Pass an answer to another AI function

Use a common table expression (CTE) or a `FROM` subquery when one AI function
reads another AI answer. A CTE gives the first answer a column name.

For example, the query first summarizes each review and then classifies each
summary:

```sql
WITH summaries AS (
    SELECT r.id,
           AI.MAP(r.body, 'Summarize the review.', 32) AS summary
    FROM reviews r
)
SELECT s.id,
       AI.CLASSIFY(s.summary, ['praise', 'complaint', 'mixed']) AS kind
FROM summaries s;
```

## Reduce model work

DataFusion applies a stored-value filter before an AI function over the same
rows. The query below sends only reviews with at least four stars to the
model:

```sql
SELECT r.id
FROM reviews r
WHERE r.stars >= 4
  AND AI.IF(PROMPT('Does the reviewer request a refund? {0}', r.body));
```

A stored-value join condition also reduces the pairs sent to the model. Add
the stored condition beside the AI condition in `JOIN ... ON`.

Sorting and aggregation can need answers for more rows than `LIMIT` returns.
Use `query.explain()` to inspect the planned model work.

## Filter an answer

`WHERE` cannot read a name defined in the same `SELECT` list. Repeat the AI
call when a query returns and filters the same answer. Quail evaluates
identical calls once.

```sql
SELECT r.id,
       AI.SCORE(PROMPT('Does the reviewer request a refund? {0}', r.body))
           AS refund_score
FROM reviews r
WHERE AI.SCORE(
    PROMPT('Does the reviewer request a refund? {0}', r.body)
) > 0.8;
```

## Choose a SQL dialect

`session.sql()` uses Snowflake syntax by default. Pass `dialect="bq"` for
BigQuery syntax. The dialect changes ordinary SQL syntax and the syntax for
AI function options.

Quail also registers three text functions for dialect compatibility:

| Function | Behavior |
| --- | --- |
| `REGEXP_CONTAINS(value, pattern)` | BigQuery syntax; matches anywhere in the value. |
| `REGEXP_LIKE(value, pattern)` | BigQuery syntax matches anywhere; Snowflake syntax matches the whole value. |
| `RLIKE(value, pattern)` | Snowflake alias for `REGEXP_LIKE`. |

Use a DataFusion scalar function inside an AI prompt when the model should
read the transformed value. For example,
`PROMPT('Review: {0}', LOWER(TRIM(r.body)))` removes surrounding spaces and
converts the review to lowercase before the model reads it.
