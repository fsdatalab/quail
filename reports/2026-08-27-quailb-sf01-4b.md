# QuailB SF 0.1 with Qwen3 4B fp8

## Setup

- The benchmark has all 35 QuailB queries at scale factor 0.1.
- Every engine uses Qwen3 4B fp8 on one H100!.
- Query time excludes model startup.
- GPU cost uses $3.9492 per H100! hour.
- Quail uses pipelining, token based admission, and KV rewind.
- Stock vLLM submits filters in stage major waves. Each filter stage is one
  `generate()` call. Joins use the full document cross product.
- Pipelined vLLM submits the next filter as soon as each document passes its
  current filter. It uses the same join code as stock vLLM.
- All three measured systems use the same document first filter and join
  prompts.
- The SoL estimate uses ground truth survivor counts. It is an estimate of the
  required model work. It is not the output of the production planner.

## Prediction

The old stock vLLM filter prompt had the task before the document. Quail and
pipelined vLLM used the document first prompt. Rerunning stock vLLM with the
canonical prompt should make its survivor counts match pipelined vLLM. It
should also reduce the apparent Quail speedup on the affected queries.

LEP-2 was also stale after the LePaRD corpus changed. The corrected LEP-2 run
should evaluate 500 times 433, or 216,500, document pairs. Its time should be
close to the 155.50 second pipelined vLLM result because the two systems use the
same join code.

## Result

The prediction was correct.

- Stock vLLM and pipelined vLLM perform the same number of filter and join
  evaluations on 34 of 35 queries.
- BIO-4 differs by one filter decision out of 313 filter evaluations. The
  prompt token ids are identical. The different batching schedule changed one
  fp8 decision.
- On the 18 filter queries whose corpora did not change, the geometric mean
  stock vLLM to Quail runtime ratio fell from 3.02 times to 2.69 times. The
  geometric mean gives every query equal weight.
- LEP-2 evaluated the expected 216,500 pairs. It took 177.67 seconds, compared
  with 155.50 seconds for pipelined vLLM.
- Across all 35 queries, Quail took 1,043.52 seconds. Stock vLLM took 3,128.62
  seconds. Pipelined vLLM took 3,214.50 seconds.
- Quail was faster than stock vLLM on 33 of 35 queries.
