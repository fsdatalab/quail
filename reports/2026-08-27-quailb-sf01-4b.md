# QuailB SF 0.1 with Qwen3 4B fp8

## Setup

- The benchmark has all 35 QuailB queries at scale factor 0.1.
- Every engine uses Qwen3 4B fp8 on one H100!.
- Query time excludes model startup.
- GPU cost uses $3.9492 per H100! hour.
- Quail uses pipelining, token based admission, and KV rewind.
- Stock vLLM submits filters in stage major waves. Each filter stage is one
  `generate()` call. Joins use the full document cross product.
- Pipelined vLLM submits the next filter as soon as each document passes its
  current filter. It uses the same join code as stock vLLM.
- Both vLLM configurations ran in the same model process for each dataset.
  KV was cleared before each query and configuration.
- All three measured systems use the same document first filter and join
  prompts.
- Stock vLLM and pipelined vLLM measured 34 queries. BIO-8 is not measured.
  The BioDEX process timed out after BIO-7, and the BIO-8 rerun was cancelled.
- The SoL estimate uses ground truth survivor counts. It is an estimate of the
  required model work. It is not the output of the production planner.
- The measured runs predate the fixed selectivity estimates and use the query
  order written at the time. The current SoL estimate uses cost based filter
  order. A confirming GPU run has not been made yet.

## Prediction

Pipelined filter submission should reduce filter only time compared with stock
vLLM stage major waves. Join only times should remain close because both
configurations use the same join code.

## Result

The prediction was correct.

- Across the seven filter only queries, pipelined vLLM processed 233.2 input
  documents per second. Stock vLLM processed 136.0.
- Across the ten join only queries, pipelined vLLM processed 425.2 document
  pairs per second. Stock vLLM processed 421.1.
- Across the 34 queries measured by both baselines, Quail took 967.11 seconds.
  Stock vLLM took 4,301.37 seconds. Pipelined vLLM took 4,162.49 seconds.
- Quail was 4.45 times faster than stock vLLM and 4.30 times faster than
  pipelined vLLM on those 34 queries, using total time.
- Quail was faster than each vLLM configuration on 32 of the 34 measured
  queries.
- BIO-8 remains null for both vLLM configurations. The plot does not draw bars
  for these missing values.
