Packed forward pass, with one attention path selected for each workload

Filters and joins use the same packed forward pass. Filters select unified, while joins select merge_quant. A filter chunk contains documents and filter questions. A join chunk contains anchors and partner suffixes. The outlined attention section is the only part of the layer loop that changes. Kernel launch counts are per layer. Rows are aligned across columns, and matching labels identify the same kernel. The number at the left of each chip is its launch order, not a kernel version. A tall chip is one fused kernel spanning the rows of the kernels it replaces.

d The anchor KV lives in arena pages, so partner suffixes use a second non-causal attention call. e The final kernel merges both attention results and quantizes them for the output projection. Packed unified is also correct on joins. The measured join selects this path because it is faster.

Unified and merge_quant on the same join

Both paths put several suffixes for the same anchor in one forward pass. Unified uses one paged FA3 call. merge_quant uses two attention calls and merges their results.
