# Documentation site

Quail now has a documentation site under `docs/`. It is a Fumadocs site
on Next.js, and the pages are MDX files under `docs/content/docs/`.

The site has four parts, modeled on the DataFusion documentation:

- A user guide: installation, a quickstart, the SQL reference, the
  Python builder API, data sources, configuration, results and explain,
  running on Modal, and running QUAIL-B.
- An architecture section: the query path, logical plans, physical
  plans, the Quail backend, the request backends, and the compute
  worker.
- An extending section: the extension registry, table providers,
  logical nodes and rules, physical nodes and planners, model backends,
  compute providers, execution observers, adding a model, and using
  Quail from DataFusion. The code examples come from the test suite.
- A contributing section: repository layout and checks, experiment
  rules, reports and plots, and the writing and naming rules.

Diagrams render with a small Mermaid client component. The site also
serves `llms.txt` and per page Markdown, which Fumadocs generates.

To run it:

```bash
cd docs
pnpm install
pnpm dev
```

`pnpm build` prerenders all 29 pages. The build is not part of CI.
