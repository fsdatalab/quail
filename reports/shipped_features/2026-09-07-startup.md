# Shared model files and kernel compilation

The parent process resolves the pinned Hugging Face model revision before
starting GPU children. Every child receives the same local snapshot directory.
vLLM loads from that directory, so each GPU no longer resolves the model on
the Hub independently. Resolution is cached by model and revision for later
queries in the same process. A direct single-GPU load uses the same resolver.
The coordinator sends an explicit boot request and waits for every GPU to
finish warming before starting the query. Filter and join operators no longer
load or warm models. Startup time covers file preparation, child process
startup, model loading, and warmup. Query time starts after all GPUs are ready.

Kernel warmup now holds a file lock around the completion check, compilation,
and completion write. Only one worker sharing that cache performs the full
compile pass for the same hardware, software, model, and budget. Other workers
wait and then exercise cached kernels in parallel. The completion file is
written only after GPU synchronization succeeds. A failed compile releases
the lock without publishing completion, so another worker can retry.

Each GPU still runs forward passes to load and exercise its kernels. The
cached warmup now includes the join path. The warmup version changed to
invalidate completion files from the earlier implementation.

Quail logs identify the GPU worker, such as `[quail][GPU 3]`. The matrix
multiplication warmup uses periodic INFO messages instead of a progress bar.
INFO output reports the major warmup phases and completion. Individual
attention shapes and forward passes are DEBUG messages. Reported warmup
duration separates waiting for compilation from running the warmup itself.

The IMDB demo defaults to the shared Modal price map in
`quail.bench.evaluate.MODAL_GPU_USD_PER_HOUR`. Its GPU-only rates are
$3.9492 per hour for H100 and $3.0312 per hour for RTX PRO 6000, from
[Modal pricing](https://modal.com/pricing), checked September 7, 2026.
The demo prints the price source and accepts an explicit price override.

Redundant configuration cases, constant-copy assertions, and mocked argument
forwarding tests were removed. The retained startup tests cover preparation
order, shared compilation, and failure recovery.

CPU tests verify shared model resolution, startup ordering and time
accounting, GPU labels, and compilation failure recovery. A test with three
separate processes verifies one compile pass and two concurrent cached
warmups. GPU execution of these startup changes has not been measured.
